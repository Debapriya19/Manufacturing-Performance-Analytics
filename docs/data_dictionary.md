# Data dictionary

The plant, company and figures are fictional. The data is synthetic, generated by `scripts/generate_data.py` (seed 42) to look like real exports from a plant's MES (manufacturing execution system), QMS (quality management system) and ERP. Say this openly in interviews: the value of the project is the method, and generated data lets the story contain real, discoverable problems.

**Why synthetic rather than a public dataset?** Public OEE datasets are either single-machine sensor data (no shifts, SKUs or stop reasons) or toy tables without data-quality problems. Hiring managers in manufacturing analytics want to see time-based KPIs from MES-style data with planned vs unplanned stops, and the messy joins that come with it. Generating the data makes that possible and fully reproducible.

## Target clean model

The tables the cleaning step should produce.

### FactProduction (14,240 rows): one row per line per production hour

| Column | Type | Description |
|---|---|---|
| HourStart | datetime | Start of the clock hour |
| ProductionDate | date | Production day (06:00 to 06:00) |
| Shift | text | A, B or C |
| LineID | text | L1-L4 |
| SKU | text | Product running that hour |
| ScheduledMinutes | int | Always 60 for a scheduled hour |
| PlannedStopMinutes | int | Breaks and sanitation in the hour |
| DowntimeMinutes | int | Unplanned stop minutes in the hour |
| RunMinutes | int | Scheduled - planned stops - downtime |
| TotalUnits | int | Packs produced including rejects |

### FactDowntime (13,626 rows): one row per stop event

EventID, ProductionDate, Shift, LineID, MachineID, ReasonCode, StartTime, EndTime, DurationMinutes, Comment. Includes planned stops (PL-xx); filter `DimDowntimeReason[IsPlanned] = FALSE` for losses. Unplanned minutes reconcile exactly with the sum of FactProduction[DowntimeMinutes].

### FactRejects (8,874 rows): one row per date, shift, line, SKU and reject reason

ProductionDate, Shift, LineID, SKU, RejectReasonCode, RejectUnits (zero rows removed).

### Dimensions

| Table | Key | Main attributes |
|---|---|---|
| DimDate | Date | Year, MonthNo, Month, ISOWeek, WeekStart, DayOfWeekNo, DayOfWeek, IsWeekend |

## Downtime reason codes

| Code | Description | Category | Planned |
|---|---|---|---|
| PL-01 | Scheduled break | Planned stop | Yes |
| PL-02 | Sanitation / clean-down | Planned stop | Yes |
| CO-01 | Product changeover | Changeover | No |
| CO-02 | Film / reel change | Changeover | No |
| BD-01..04 | Mechanical, electrical/sensor, seal jaw/heater, pneumatic | Breakdown | No |
| MS-01 / MS-02 | Product jam / film tracking (logged stops of 2-10 min) | Minor stop | No |
| MT-01 / MT-02 | Waiting for packaging / waiting for product | Material | No |
| QA-01 | QA hold / line clearance | Quality hold | No |
| OP-01 | No operator available | Staffing | No |

Stops shorter than 2 minutes are not logged by the MES; they show up as performance (speed) loss, as in most real plants.
